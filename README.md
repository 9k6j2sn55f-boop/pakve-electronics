# Pakve Electronics & Furniture — Official Showroom Platform

A responsive, ultra-lightweight multi-page digital showroom website engineered for Pakve Electronics & Furniture (Kalamb, Maharashtra).

## Architecture & Tech Stack
- Engine: Semantic HTML5, Pure CSS3 (Design Tokens), ES6 JavaScript
- Build Tool: Vite
- Deployment: Vercel Edge Network

## Setup & Commands
```bash
npm install
npm run dev
npm run build
npm run preview
```
